# 💖 Kirsten & Ycany's Memory Vault Photos Folder

Place all your favorite photos, polaroids, date snapshots, and memories inside this folder! 🌸

How to add them to your Monthsary website:
1. Put any photos you want inside this folder (`memory_vault_photos`).
2. Open your website (`index.html`).
3. Click "Add Memory" or "Upload Photos".
4. Select the pictures from this folder to add them into your scrolling marquee & album with custom locations and notes!
